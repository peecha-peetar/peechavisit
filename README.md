# پیچا ویزیت | PeechaVisit

سامانهٔ ردیابی و مدیریت ویزیتورهای فروش میدانی — نسخهٔ **۲.۲**
وب‌سایت: [peecha.ir](https://peecha.ir)

ویزیتور از طریق اپلیکیشن موبایل (PWA) ویزیت مشتری، ثبت سفارش و دریافت‌های مالی
(نقدی / چک / حواله) را به همراه موقعیت GPS و عکس ثبت می‌کند؛ مدیر از طریق داشبورد و
پنل مدیریت، همه‌چیز را روی نقشه و در جدول‌ها می‌بیند و کاربران را مدیریت می‌کند.

---

## 🔑 اطلاعات ورود پیش‌فرض

> این‌ها کاربران پیش‌فرضی هستند که اسکریپت `create_tables.py` می‌سازد و در دیتابیس فعلی
> شما هم (`tracking.mdf` داخل `DATA.rar`) با همین رمز ذخیره شده‌اند:

| نام کاربری | رمز عبور   | نقش      |
|------------|------------|----------|
| `admin`    | `admin123` | مدیر     |
| `visitor1` | `admin123` | ویزیتور  |

رمز به‌صورت `SHA256` ذخیره می‌شود. بعد از اولین ورود، حتماً از پنل مدیریت
(`admin.py`) رمزها را عوض کنید.

---

## 🧩 اجزای پروژه

| فایل | پورت | توضیح |
|------|------|-------|
| `app.py` | `5000` | Flask API — بک‌اند اپلیکیشن موبایل (توکن HMAC) |
| `run_client.py` | `8000` | سرو کردن اپلیکیشن موبایل PWA (`pwa_client/`) |
| `dashboard.py` | `8501` | داشبورد مدیر (Streamlit) — ویزیت‌ها، سفارش‌ها، دریافت‌ها روی نقشه |
| `admin.py` | `8502` | پنل مدیریت کاربران (Streamlit) |
| `create_tables.py` | — | ساخت دیتابیس و جدول‌ها (فقط یک‌بار اجرا شود) |
| `auth.py` | — | منطق احراز هویت و قفل‌شدن حساب |
| `config.py` | — | **تنها فایل تنظیمات** — IP سرور، پورت‌ها، امنیت |

**دیتابیس‌ها (SQL Server):**
- `tracking` — دیتابیس خودِ برنامه: `visitors`, `visits`, `orders`, `order_items`, `payments`, `submitted_uids`
- `dejavuDB1` — دیتابیس فروش موجود (فقط خواندن): جدول‌های `customer`, `article`

---

## ⚙️ پیش‌نیازها

- **ویندوز** با **SQL Server** (برنامه با `Trusted_Connection` / احراز هویت ویندوز وصل می‌شود)
- **Python 3.12**
- **ODBC Driver** برای SQL Server (`SQL Server` یا `ODBC Driver 17/18 for SQL Server`)

> ⚠️ این برنامه برای اجرا روی **ویندوز در کنار SQL Server** نوشته شده و روی لینوکس/ابر
> بدون تغییر اجرا نمی‌شود (به‌خاطر `pyodbc` + درایور SQL Server + اتصال Trusted ویندوز).

## 🚀 راه‌اندازی (قدم‌به‌قدم)

### ۱) بازگردانی دیتابیس
فایل‌های `tracking.mdf` و `tracking_log.ldf` (داخل `DATA.rar`) را در SQL Server
خود **Attach** کنید، یا اگر دیتابیس جدید می‌خواهید این مرحله را رد کرده و فقط
`create_tables.py` را اجرا کنید.

### ۲) نصب وابستگی‌ها
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### ۳) تنظیم `config.py`
داخل `config.py` این مقادیر را با سرور خودتان تنظیم کنید:
```python
"SERVER_NAME": "SERWIN\\RAD",      # نام SQL Server شما
"SERVER_IP":   "10.165.254.180",   # IP این کامپیوتر در شبکه
```
و حتماً `SESSION_SECRET` را به یک مقدار تصادفی و مخفی تغییر دهید.

### ۴) ساخت جدول‌ها (فقط اگر دیتابیس را attach نکردید)
```bash
python create_tables.py
```

### ۵) اجرای سرویس‌ها (هرکدام در یک پنجرهٔ ترمینال جدا)
```bash
python app.py
```
```bash
python run_client.py
```
```bash
streamlit run dashboard.py --server.port 8501
```
```bash
streamlit run admin.py --server.port 8502
```

### ۶) دسترسی
- 📱 اپلیکیشن موبایل ویزیتور: `http://<IP-سرور>:8000`
- 📊 داشبورد مدیر: `http://<IP-سرور>:8501`
- 🛠 پنل مدیریت کاربران: `http://<IP-سرور>:8502`

موبایل و کامپیوترها باید در یک شبکهٔ محلی باشند.

## 🔒 نکات امنیتی و دادهٔ حساس

- فایل‌های دیتابیس (`*.mdf`, `*.ldf`, `*.rar`) و تصاویر واقعی چک/حواله/سلفی
  **به‌صورت عمدی در گیت قرار نمی‌گیرند** (`.gitignore`) چون شامل اطلاعات مالی و شخصی
  مشتریان هستند. این‌ها را جدا و امن نگه دارید.
- `SESSION_SECRET` در `config.py` و کلید fallback در `app.py` را حتماً عوض کنید.
- رمزهای پیش‌فرض `admin123` را بعد از اولین ورود تغییر دهید.
